Handelskalkulation ist das Verfahren zur Berechnung von Verkaufspreisen auf Basis von Einkaufspreisen. Eine richtige Kalkulation sichert Rentabilität und Wettbewerbsfähigkeit.

## Grundbegriffe

### Einkaufspreis (EKP)
Der Preis, den ein Unternehmen für ein Produkt zahlt.

**Beispiel:** PC-Besteller kauft bei Distributor für 600€

### Selbstkosten
Einkaufspreis + betriebliche Kosten (Personal, Lagerung, Administration)

**Beispiel:** 600€ EKP + 80€ Betriebskosten = 680€ Selbstkosten

### Gewinnzuschlag (Markup)
Prozentualer Aufschlag auf die Selbstkosten zur Gewinnerzielung.

**Beispiel:** 680€ × 1,30 = 884€ (30% Markup)

### Verkaufspreis (VKP)
Der Preis, den der Kunde zahlt.

**Beispiel:** 884€

### Gewinn
Differenz zwischen Verkaufspreis und Selbstkosten.

**Beispiel:** 884€ - 680€ = 204€ Gewinn

---

## Kalkulationsmethoden

### 1. Additive Kalkulation (Markup-Verfahren)

$$\text{VKP} = \text{EKP} + \text{Zuschläge} + \text{Gewinn}$$

**Beispiel:**
- EKP: 500€
- Gemeinkosten-Zuschlag (10%): 50€
- Gewinn-Zuschlag (20%): 100€
- **VKP = 650€**

### 2. Kalkulation mit Gewinnmarge

Die Gewinnmarge ist der prozentuale Gewinn vom Verkaufspreis.

$$\text{Gewinnmarge (\%)} = \frac{\text{Gewinn}}{\text{VKP}} \times 100$$

**Beispiel:**
- EKP: 800€
- VKP: 1.200€
- Gewinn: 400€
- Gewinnmarge = (400 / 1.200) × 100 = **33,3%**

### 3. Gewinnmarge rückwärts berechnen

Wenn man die Gewinnmarge kennt und einen VKP braucht:

$$\text{VKP} = \frac{\text{EKP}}{1 - \text{Gewinnmarge}}$$

**Beispiel:**
- EKP: 500€
- Gewünschte Gewinnmarge: 25%
- VKP = 500 / (1 - 0,25) = 500 / 0,75 = **666,67€**

## Kalkulationszuschläge

### Gemeinkosten-Zuschlag (GKZ)
Kostenanteil für Verwaltung, Personal, Lagerung.

| Zuschlag | Anwendung |
|---|---|
| 5–10% | Hardware mit hohem Umsatz |
| 15–25% | Spezialisierte Software, Services |
| 30–50% | Individuelle Lösungen, Consulting |

### Gewinn-Zuschlag (GWZ)
Gewinnspanne für Rentabilität.

| Zuschlag | Anwendung |
|---|---|
| 10–15% | Massenprodukte (Monitor, Tastatur) |
| 20–30% | Standardgeräte (Server, PCs) |
| 30–50% | Speziallösungen, Support |
| 50%+ | Consulting, benutzerdefinierte Systeme |

## Praktische Kalkulationsbeispiele

### Beispiel 1: Standard-PC

| Position | Betrag |
|---|---|
| **Einkaufspreis** | 700€ |
| Gemeinkosten (15%) | +105€ |
| **Selbstkosten** | 805€ |
| Gewinn-Zuschlag (25%) | +201€ |
| **Verkaufspreis (netto)** | **1.006€** |
| MwSt. (19%) | +191€ |
| **Verkaufspreis (brutto)** | **1.197€** |

**Gewinnmarge = 201 / 1.006 = 19,9%**

### Beispiel 2: Individualisierte Softwarelösung

| Position | Betrag |
|---|---|
| **Einkaufspreis (Lizenz)** | 5.000€ |
| Gemeinkosten Analyse & Setup (30%) | +1.500€ |
| Schulung & Dokumentation (20%) | +1.000€ |
| **Selbstkosten** | 7.500€ |
| Gewinn-Zuschlag (40%) | +3.000€ |
| **Verkaufspreis (netto)** | **10.500€** |
| MwSt. (19%) | +1.995€ |
| **Verkaufspreis (brutto)** | **12.495€** |

**Gewinnmarge = 3.000 / 10.500 = 28,6%**

### Beispiel 3: Service / Consulting (Stundensätze)

| Komponente | Betrag |
|---|---|
| **Brutto-Stundenlohn Mitarbeiter** | 35€ |
| Gemeinkosten & Infrastruktur (50%) | +17,50€ |
| **Selbstkosten/Stunde** | 52,50€ |
| Gewinn-Marge (60%) | +31,50€ |
| **Kalkulationsstundensatz** | **84€** |
| **Verkaufsstundensatz (für Kunde)** | **120€** |

**Brutto-Gewinn pro Stunde = 120 - 52,50 = 67,50€ (56%)**

## Psychologische Preisgestaltung

### Charming Prices (Preisreize)

Preise mit psychologischen Effekten:
- **99€** statt 100€ (wirkt günstiger)
- **999€** statt 1.000€ (fast 50% billiger wahrgenommen)
- **29,95€** statt 30€ (Schwelle-Effekt)

### Premium Pricing
Höhere Preise für Qualität/Prestige:
- "Enterprise" Version teurer als "Standard"
- Höherer Preis signalisiert Qualität
- 20–40% Aufschlag möglich

### Bundling
Kombinierte Preise für mehrere Produkte:
- PC + Monitor + Software: Paketpreis
- Bis zu 15% Rabatt auf Paket
- Höherer Gesamtumsatz möglich

## Konkurrenzanalyse

### Marktsituationen

| Situation | Strategie | Typische Marge |
|---|---|---|
| **Wettbewerb hoch** | Preisanpassung | 15–20% |
| **Wettbewerb normal** | Markenstandardpreis | 25–35% |
| **Wettbewerb niedrig** | Premium Pricing | 40–60% |
| **Monopol / Spezialist** | Maximale Marge | 50%+ |

### Wettbewerbsfähige Kalkulation

1. Konkurrenzpreise recherchieren
2. Eigene Kostenstruktur überprüfen
3. Differenzierung identifizieren (Service, Qualität, Support)
4. Marge anpassen ohne Rentabilität zu opfern

**Faustregel:** Man kann nicht auf Dauer unter Kosten verkaufen!

## Fehler in der Kalkulation

### ❌ Zu niedrige Marge

**Problem:** 10% Gewinn statt 25%
- Bei 1.000€ Umsatz: 100€ statt 250€ Gewinn
- Kaum Puffer für Kostenanstieg
- Unrentabilität droht

### ❌ Versteckte Kosten ignorieren

**Problem:** Nur Einkaufspreis + fester Zuschlag
- Zusätzliche Kosten (Versand, Rückgaben, Kulanz) nicht berücksichtigt
- Marge schmilzt in der Praxis

**Lösung:** Alle Kosten erfassen, regelmäßig überprüfen

### ❌ Nicht kalkulierte Sonder-Ausgaben

**Problem:** Kostenloses Setup, Schulung nicht berechnet
- Betriebsblind werden
- Gewinn wird aufgezehrt

**Lösung:** Alle Leistungen separat kalkulieren oder in Zuschlag einrechnen

### ❌ Nicht regelmäßig überprüft

**Problem:** Kalkulation von vor 2 Jahren, Kosten sind gestiegen
- EKP um 10% gestiegen, Marge fällt um 8%
- Rentabilität leidet

**Lösung:** Halbjährlich (oder bei Kostensprung) neu kalkulieren

## Kalkulation für verschiedene Geschäftsmodelle

### Hardware-Verkauf
- Marge: 15–25%
- Begründung: Hoher Umsatz, Konkurrenz, geringe Differenzierung

### Software-Lizenzverkauf
- Marge: 25–40%
- Begründung: Höherer Wertschöpfung, kleinere Stückzahlen

### Consulting & Services
- Marge: 40–70% (auf Stundensätze)
- Begründung: Hohe Wertschöpfung, Expertise, variable Nachfrage

### SaaS (Software-as-a-Service)
- Marge: 50–80%
- Begründung: Skalierbar, keine physische Logistik, wiederkehrende Einnahmen

## Checkliste Kalkulationsprüfung

- [ ] Alle Einkaufskosten erfasst
- [ ] Gemeinkosten-Zuschlag angemessen (15–30%)
- [ ] Gewinnzuschlag wettbewerbsfähig
- [ ] MwSt. korrekt berücksichtigt (19% in Deutschland)
- [ ] Psychologische Preisgestaltung genutzt
- [ ] Konkurrenzpreise verglichen
- [ ] Marge >= 20% (Faustregel)
- [ ] Sonder-Leistungen separat kalkuliert
- [ ] Kalkulation halbjährlich überprüft
- [ ] Break-Even-Punkt bekannt (ab welcher Menge wird Gewinn erzielt?)
